# Search Index Schema

This document describes the structure of `search-index.json`, the static search index generated by `scripts/build-local-search-index.js`.

## Top-Level Structure

```typescript
interface SearchIndex {
  schemaVersion: number;        // 1
  generatedAt: string;          // ISO 8601 timestamp
  editorialStages: Record<string, string>;
  guidedTrails: GuidedTrail[];
  methodology: Methodology;
  chunking: ChunkingConfig;
  stats: Stats;
  facets: Facets;
  works: Work[];
  chunks: Chunk[];
}
```

## Works

Each work represents a single mythological text.

```typescript
interface Work {
  id: string;                   // Controlled doc_id (e.g., GRK_ILIAD_BUTLER)
  title: string;
  culture: string;              // Culture group (e.g., Greek, Norse, Egyptian)
  languageOriginal: string | null;  // ISO 639-3 code
  summary: string;
  sourceUrl: string | null;
  sourceTitle: string | null;
  translator: string | null;
  provenance: Provenance;
  tags: WorkTags;
  chunkCount: number;
}

interface Provenance {
  rights: string;
  sourceQuality: string;
  completeness: string;
  translationCompleteness: string;
  editorialStatus: string;
  tagReview: string;
  notes: string;
  confidence: number;           // 0.05–0.99
}

interface WorkTags {
  mythType: string[];
  theme: string[];
  archetype: string[];
  social: string[];
  cognitive: string[];
  rite: string[];
  episode: string[];
  proppian: string[];
}
```

## Chunks

Chunks are overlapping passages of ~650 words, split by Markdown headings.

```typescript
interface Chunk {
  id: string;                   // workId:hash
  workId: string;
  workTitle: string;
  culture: string;
  sectionTitle: string;         // Markdown heading that introduced this section
  text: string;                 // Plain text of the chunk
  tokenCount: number;           // Word count
  wordStart: number;
  wordEnd: number;
  chunkIndex: number;
  stableCitation: string;       // e.g., GRK_ILIAD_BUTLER §42
  sourceUrl: string | null;
  tags: ChunkTags;
  tagConfidence: TagConfidence;
  workTags: WorkTags;           // The work's original frontmatter tags
  entities: Entities;
  provenance: Provenance;
  interpretation: Interpretation;
  bm25Text: string;             // Concatenated text for lexical search
}

interface ChunkTags {
  mythType: string[];
  theme: string[];
  archetype: string[];
  social: string[];
  cognitive: string[];
  rite: string[];
  episode: string[];
  proppian: string[];
}

interface TagConfidence {
  [category: string]: {
    [tagCode: string]: number;  // 0.25–0.99
  };
}

interface Entity {
  id: string;
  name: string;
  type?: string;
  culture?: string;
  domains?: string;
  description?: string;
  roleInWork?: string;
  aliases?: string[];
  notes?: string;
  source?: string;
}

interface Entities {
  figures: Entity[];
  creatures: Entity[];
}

interface Interpretation {
  method: string;               // "automated-controlled-vocabulary-heuristic"
  reviewedBy: string;
  caveat: string;
}
```

## Tag Categories

All tag codes use controlled vocabularies defined in `Corpus Forge/lexicons/`:

| Category | Prefix | File | Example |
|----------|--------|------|---------|
| Myth Type | `MYTHTYPE_` | `myth_type_tags.csv` | `MYTHTYPE_COSMOGONY` |
| Theme | `THM_` | `theme_tags.csv` | `THM_HERO_JOURNEY` |
| Character Archetype | `ARCH_` | `character_archetype_tags.csv` | `ARCH_TRICKSTER_ARCHETYPE` |
| Social Role | `FUNC_` | `social_role_tags.csv` | `FUNC_WARRIOR` |
| Cognitive Function | `COG_` | `cognitive_function_tags.csv` | `COG_AGENCY_DETECTION` |
| Rite | `RITE_` | `rite_tags.csv` | `RITE_SACRIFICE` |
| Myth Episode | `EP_` | `myth_episode.csv` | `EP_MONSTER_SLAYING` |
| Proppian Function | `PROPP_` | `proppian_functions.csv` | `PROPP_01_ABSENTATION` |

## Chunking Parameters

- **Chunk size**: 650 words
- **Overlap**: 90 words
- **Minimum chunk size**: 40 words

## Confidence Scoring

Tag confidence is a blend of:
1. **Editorial stage** of the work (`machine_tagged` = 0.62 base)
2. **Source quality** bonus/penalty
3. **Textual evidence strength** (higher score = higher confidence)

Confidence decays by 0.04 per tag rank within a category.

## Source Notes

- `Homeric_Hymns.txt` in the original consolidated raw folder contained Herodotus, not the Homeric Hymns. It has been replaced by a scripted Project Gutenberg extraction from eBook 348.
- `Rg_Veda.txt` in the original consolidated raw folder was only an index stub. It has been replaced by a scripted full-book extraction from a public-domain Griffith mirror.
- `Hesiod_Theogony.md`, `Homeric_Hymns.md`, `Rg_Veda.md`, and `Shahnameh.md` are generated by `scripts/promote-available-raw-texts.js`.
- Sacred-texts.com currently blocks automated download in this environment, so the Rig Veda promotion uses a public-domain mirror of the same Griffith scan.
- `Popol_Vuh.md` was previously a template with only Part I and placeholder sections for the remaining narrative. It has been replaced with the complete Lewis Spence public-domain translation (1908) from Project Gutenberg eBook 56550.

## Known Remaining Gaps

The original starter list included the Huarochiri Manuscript. The clean English edition named there is Salomon/Urioste, a modern University of Texas Press translation, and should not be silently bundled as local text without rights clearance. The project can still represent Huarochiri later by:

- using an explicitly licensed text,
- storing only metadata and citation until rights are settled,
- adding a public-domain Spanish/Quechua transcription if a clean lawful source is selected.

**Shan Hai Jing** has comprehensive metadata and a template prepared, but no lawful public-domain English translation has been located. The file is held in `Corpus Forge/pending/` until a lawful source is identified. A public-domain Chinese original exists (e.g., ctext.org), but the archive currently indexes English translations only.

These are the only starter-list items not bundled as local full text.
